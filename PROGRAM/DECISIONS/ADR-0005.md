# ADR-0005 — Licence: the PolyForm Noncommercial License 1.0.0 for FRIEDMAN's original software and technical documentation

- **Date:** 2026-11-22 UTC (Session 8, a working session and not an exam; written on `main`
  `92367a6cea0b47db6f81ae14dbe3c4fd1ffbe4f8`).
- **Status:** **ruled by Al** (engineer of record): ruling R6 of 2026-11-22 UTC, and his order
  of the same date in the message that launched Session 8. Both are transcribed verbatim under
  *Owner decisions recorded*. The rest of this file is the executor's implementing text. Al was
  shown the whole file before the commit. He accepted it with changes, and the commit was made
  only after his answer, with those changes made: D2(b) is struck, D3 says "grants", and his
  rulings on the executor's five readings are recorded with them. His answer is transcribed
  under *Owner decisions recorded* too.
- **Scope:**
  - the licence under which FRIEDMAN's original software and technical documentation are
    offered, from the commit that accepts this ADR onward;
  - what that licence does not cover;
  - where it is stated.

  It answers the escalation in ADR-0002 (*Consequences*: the repository is public and has no
  `LICENSE` file). It does not amend the constitution, which names no licence for the
  repository; F11 governs third-party material and is unchanged. It changes no register
  status, no manifest and no result.

## Context

### FRIEDMAN has carried no licence until now

The repository has been public since 2026-08-22 (ADR-0000). From its first commit, `eced49d`,
through `92367a6` it has held no `LICENSE` file, no crate has carried a `license` field, and the
README has had no licence section. ADR-0002 escalated the choice of a licence to Al on
2026-08-25 and left the crate without a `license` field until he made it. On 2026-11-22 UTC,
before this change, the GitHub API reported the repository's licence as `null`.

## Decision

- **D1 — The licence.** From the commit that accepts this ADR, FRIEDMAN's original software and
  technical documentation are licensed under the **PolyForm Noncommercial License 1.0.0** (SPDX
  `PolyForm-Noncommercial-1.0.0`).
  - Copyright is held personally by **Alexander David Zalewski**.
  - `LICENSE` begins with the Required Notice line that R6 gives, then one blank line, then the
    verbatim PolyForm text (S-0006). The line, copied by script from R6:

    ```text
    Required Notice: Copyright 2026 Alexander David Zalewski (https://github.com/Quigles1337/FR13DMAN)
    ```

  - Commercial use requires a separate licence from the copyright holder. The contact line is
    Al's, copied by script from his order and not from SYNDEOM:

    ```text
    For commercial licensing, contact Alexander David Zalewski at adz@alphx.io.
    ```

- **D2 — What this licence does not cover.**
  - (a) Third-party material keeps its own licence per F11, as SOURCES.md records it:
    - the Rust dependencies (S-0005);
    - any copy of a source, should one ever be committed (none is: SOURCES.md, storage rule);
    - anything placed under `quarantine/`, and any third-party corpus or code ingested later
      (F4.1, F4.2, F2.1(iii)), each recorded in SOURCES.md before it is added;
    - the short quotations from cited sources inside FRIEDMAN's own files, and RFC 8785's test
      vectors in the engine's tests (S-0004). They remain their authors'.
  - SYNDEOM's D2(b) is not followed. It does not apply to FRIEDMAN: nothing here is separately
    controlled, and R6 follows SYNDEOM's D2 only so far as it applies (Al's ruling of
    2026-11-22 UTC, in his answer).
- **D3 — No earlier licence.** FRIEDMAN carried no licence before the commit that accepts this
  ADR. Every commit from `eced49d` through `92367a6` was published without one, and this ADR
  grants no licence for any of them.
- **D4 — Where the licence is stated:**
  - `LICENSE` (D1);
  - README § Licence: a plain-language summary and the contact line;
  - the crate `friedman-manifest`: `license = "PolyForm-Noncommercial-1.0.0"`;
  - S-0006 in SOURCES.md;
  - STATE: the Licence bullet;
  - HANDOFF Session 8.
- **D5 — Historical records are not rewritten.** ADR-0002's escalation and its sentence that
  the crates carry no `license` field, R6's "Until then", and the earlier statements in STATE's
  tables and in HANDOFF that there is no `LICENSE` file stay as written. Each records what was
  true when it was written.

## The executor's readings

Five places where R6 and Al's order left a choice to the text. They are the executor's, and
they were put to Al with this file before the commit. He ruled on them in his answer: readings
1, 3, 4 and 5 stand, and reading 2 is changed as he ordered.

1. **"Held personally" (D1).** R6 does not use these words. They are in Syndeom's D1, which R6
   says to follow, and R6's Required Notice names Al and no company.
2. **Syndeom's D2(b) is not followed.** Syndeom's D2(b) carries forward a boundary that an
   earlier ruling drew for SYNDEOM. FRIEDMAN has no such earlier ruling and no file marked as
   separately controlled. The executor first wrote D2(b) into this ADR as a rule with nothing
   to apply to yet. Al struck it: it does not apply to FRIEDMAN.
3. **The sweep report is under D1.** It is a program document that Al ferried in, and the
   record names no other owner. Al's answer settles it: the sweep report is program
   documentation, and no one else controls it.
4. **Quotations and test vectors are under D2(a).** A licence can cover only what the licensor
   owns. Syndeom's ADR reads its own D2(a) the same way in an amendment. That amendment is
   noted as agreeing; it is not adopted.
5. **The pin is a commit.** SYNDEOM's record cites the text "at tag `1.0.0`". On 2026-11-22
   UTC the GitHub API showed no tag of that name: `1.0.0` is the upstream repository's default
   branch, and it moved on 2026-11-19. The licence text did not change. The pin here is the
   commit.

## Consequences

- **Publicly visible.** From the accepting commit the repository states a licence. Earlier
  commits stay reachable in the public history, and no licence is granted for them (D3).
- **GitHub's licence field may not name it.** For `Quigles1337/Syndeom`, whose `LICENSE` has the
  same form, the GitHub API reported `NOASSERTION` on 2026-11-22 UTC. `LICENSE` and the README
  state the licence; that field does not.
- **A crate added later** carries the same `license` value (ADR-0002: every future crate lives
  under `engine/`).
- **Third-party intake is unchanged.** F11 and the storage rule in SOURCES.md still decide
  whether a third-party file may be committed at all. D2(a) says only that such a file is not
  relicensed by being here. The choice between wrapping and reimplementing the MIT-licensed
  self-citation generator (F2.1(iii)) is not made here.
- **Publication is still Al's.** A licence on the repository is not publication packaging: F4.4
  and §4.6 are unchanged.
- **Unchanged:** the constitution; every CLAIM and its status; ADR-0000 to ADR-0004;
  `engine/Cargo.lock`; the engine's source and tests. `bash scripts/check.sh` prints
  `ALL GREEN` with the new `license` field.
