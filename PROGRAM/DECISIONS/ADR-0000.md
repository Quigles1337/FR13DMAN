# ADR-0000 — Repository home, hosting, and baseline hygiene

- **Date:** 2026-08-22 (Session 1)
- **Status:** accepted

## Context

FRIEDMAN needs a home. The constitution (§0, §3) requires a repo that is the program's only memory,
with a `PROGRAM/` schema identical to the sibling program KOBER. FRIEDMAN cannot share the KOBER
repo root: the deliberately identical `PROGRAM/` schema (STATE.md, CLAIMS.md, HANDOFF.md, …) would
collide with KOBER's live state files.

Al resolved the hosting question directly in Session 1: Al created the GitHub repository
`https://github.com/Quigles1337/FR13DMAN` (public, empty) on 2026-08-22 and designated it as the
FRIEDMAN home when asked. Repo visibility is therefore Al's own decision of record — the §4.6
public-facing escalation for *publication packaging* remains fully in force at F4.4 regardless of
repo visibility.

## Decision

1. **Remote:** `origin` = `https://github.com/Quigles1337/FR13DMAN` (public; created and designated
   by Al, 2026-08-22).
2. **Local working copy:** `C:\Users\LEET\FR13DMAN` on Al's machine (discovered, this session).
3. **Default branch:** `main` (discovered from the fresh clone, not assumed; note the sibling KOBER
   repo uses `master` — the difference is an artifact of clone defaults, not load-bearing).
4. **Line endings:** LF pinned repo-wide via `.gitattributes` (`* text=auto eol=lf`, binaries
   excepted), imported from the sibling program's recorded machine gotcha: `autocrlf=true` checkouts
   silently CRLF text files, which breaks any SHA-256 pinned over committed text (F6/F11 both pin
   digests). Pinning at bootstrap avoids ever recording a CRLF digest.
5. **Commit convention:** §3.8 — `[F<phase>][<CLAIM-ID or ADR-ID or INFRA>] imperative summary`.
   Commits authored as `Quigles1337 <adz@alphx.io>`.

## Consequences

- Any digest recorded over a committed text file is stable across clean clones on any platform.
- The public-from-day-0 repo means F11's storage discipline is strict from the start: no stored
  source copy is committed unless its license permits redistribution (see SOURCES.md storage rule).
- Toolchain pins (Rust, and anything else the engine needs) are NOT decided here — they belong to
  the F0.4 scaffold ADR after `rustc`/`cargo` discovery per F7.
