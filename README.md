# FR13DMAN

**FRIEDMAN** — a calibrated instrument for designedness detection: synthetic "meaning-shaped noise"
generators with dialable structural strata and ground truth by construction, coupled to a detector
battery scored as ROC/AUC curves as a function of corpus size. The deliverable is the **fooling
frontier** — where pure mechanism begins to fool each detector of language and intentional design.

This program never issues verdicts on contested artifacts. Its outputs are positions on a calibrated
ROC surface with uncertainty intervals.

**Start here:** [`PROGRAM/FRIEDMAN-PROGRAM.md`](PROGRAM/FRIEDMAN-PROGRAM.md) — the constitution.
Current state: [`PROGRAM/STATE.md`](PROGRAM/STATE.md).

Sibling program: [KOBER](https://github.com/Quigles1337/KOBER) (Linear A falsification
infrastructure). Named for Elizebeth Smith Friedman, who proved the guessers' method hollow.
